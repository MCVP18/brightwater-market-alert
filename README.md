# Brightwater Market – Alert Review Prototype

A clickable prototype of the store manager's alert review queue for Brightwater Market's loss-prevention product.

**Live prototype:** https://mcvp18.github.io/brightwater-market-alert/

## What it shows

- Alerts sorted by risk tier (High, Medium, Low), then by highest dollar amount, then oldest on a tie
- A reason label on every alert, and the Low tier collapsed by default with its count always shown
- A chart of open alerts by tier, the selected alert's details, and Confirmed issue / No issue buttons

Sign in with any district and store to see that store's real alerts from Oct 19–25, 2026 (fictional assessment data).
No password is needed.

## Running it locally

Open `index.html` in any web browser. Everything is in that one file.
